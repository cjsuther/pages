## Guía Rápida: ¿Qué Archivo Leo?

### Soy nuevo en el proyecto
1. Empieza con **QUICKSTART.md**
2. Luego lee **DESARROLLO_LOCAL.md** para configurar tu entorno
3. Lee **README.md** completo
4. Revisa **ESTRUCTURA.txt** para entender la organización
5. Ve **EJEMPLOS_DE_USO.md** para inspirarte

### Tengo un problema
1. Busca en **FAQ.md** primero
2. Si es sobre meta tags o SEO, ve a **CONFIGURACION_SEO.md**
3. Si no lo encuentras, revisa **README.md** sección "Solución de Problemas"
4. Verifica **ESTRUCTURA.txt** para asegurarte de tener todos los archivos

### Quiero mejorar el proyecto
1. Lee **SEO_Y_MEJORAS.md** completo
2. Revisa **RESUMEN.md** para entender qué hay implementado
3. Planifica según las sugerencias

### Voy a presentar el proyecto
1. Lee **RESUMEN.md** primero
2. Prepara demos con **EJEMPLOS_DE_USO.md**
3. Ten a mano **README.md** para preguntas técnicas

### Necesito instalar rápido
1. Sigue **QUICKSTART.md**
2. Usa **DESARROLLO_LOCAL.md** para el setup completo

## Recursos de Código

### Archivos Backend (PHP)
```
api/config.php          - Configuración principal
api/Database.php        - Conexión a base de datos
api/JWT.php            - Autenticación
api/auth/*.php         - Registro y login
api/pages/*.php        - CRUD de páginas
api/groups/*.php       - CRUD de grupos
api/links/*.php        - CRUD de enlaces
api/public/*.php       - Vista pública
```

### Archivos Frontend (React)
```
src/App.jsx                    - Router y contexto
src/pages/Login.jsx           - Inicio de sesión
src/pages/Register.jsx        - Registro
src/pages/Dashboard.jsx       - Panel de control
src/pages/PageEditor.jsx      - Editor de páginas
src/pages/PublicPage.jsx      - Vista pública
```

### Base de Datos
```
database.sql           - Estructura completa de DB
```

### Configuración
```
api/config.php                 - Backend
frontend/vite.config.js       - Frontend dev server
frontend/tailwind.config.js   - Estilos
.htaccess                     - Apache routing
```
