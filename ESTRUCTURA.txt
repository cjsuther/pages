FLUJO DE DATOS
==============

1. AUTENTICACIÓN:
   Usuario → Register.jsx → POST /api/auth/register.php → MySQL
                          ← JWT Token
   Usuario guarda token en localStorage

2. LISTAR PÁGINAS:
   Dashboard.jsx → GET /api/pages/index.php (+ JWT) → MySQL
                 ← Lista de páginas del usuario

3. CREAR PÁGINA:
   Dashboard.jsx → POST /api/pages/index.php (+ JWT) → MySQL
                 ← Nueva página creada

4. EDITAR PÁGINA:
   PageEditor.jsx → GET /api/pages/detail.php?id=X (+ JWT) → MySQL
                  ← Página con grupos y links

   PageEditor.jsx → PUT /api/pages/detail.php?id=X (+ JWT) → MySQL
                  ← Página actualizada

5. CREAR GRUPO:
   PageEditor.jsx → POST /api/groups/index.php (+ JWT) → MySQL
                  ← Nuevo grupo creado

6. CREAR LINK:
   PageEditor.jsx → POST /api/links/index.php (+ JWT) → MySQL
                  ← Nuevo link creado

7. VER PÁGINA PÚBLICA:
   PublicPage.jsx → GET /api/public/page.php?slug=mi-url → MySQL
                  ← Página con todos sus grupos y links


TECNOLOGÍAS POR ARCHIVO
========================

Backend (PHP):
--------------
- config.php          → Configuración, constantes, CORS headers
- Database.php        → PDO, conexión MySQL, manejo de errores
- JWT.php             → Encoding/Decoding JWT, validación de tokens
- auth/*.php          → Registro, login, hashing de contraseñas
- pages/*.php         → CRUD de páginas, validaciones
- groups/*.php        → CRUD de grupos, relaciones con pages
- links/*.php         → CRUD de links, relaciones con groups
- public/*.php        → Consultas públicas sin autenticación

Frontend (React):
-----------------
- App.jsx             → React Router, Context API, Auth provider
- Login.jsx           → Formularios, fetch API, manejo de errores
- Register.jsx        → Validación de contraseñas, registro
- Dashboard.jsx       → Listado, modales, state management
- PageEditor.jsx      → CRUD completo, color pickers, formularios
- PublicPage.jsx      → Renderizado dinámico con estilos inline
- *.css               → Tailwind CSS, utility classes


CONFIGURACIÓN REQUERIDA
========================

1. MySQL:
   - Crear base de datos: personal_pages
   - Ejecutar: database.sql
   - Usuario con permisos: SELECT, INSERT, UPDATE, DELETE

2. PHP:
   - Versión: 7.4 o superior
   - Extensiones: pdo, pdo_mysql
   - Editar: api/config.php (credenciales DB y JWT_SECRET)

3. Apache:
   - mod_rewrite habilitado
   - AllowOverride All (para .htaccess)

4. Node.js:
   - Versión: 16 o superior
   - Ejecutar: npm install (en carpeta frontend)
   - Editar: src/App.jsx (URL de la API)


URLS DE LA APLICACIÓN
======================

Frontend:
---------
/                      → Redirige a /login o /dashboard
/login                 → Página de inicio de sesión
/register              → Página de registro
/dashboard             → Panel de control (lista de páginas)
/page/:id              → Editor de página específica
/p/:slug               → Vista pública de página

API:
----
POST   /api/auth/register.php
POST   /api/auth/login.php
GET    /api/pages/index.php
POST   /api/pages/index.php
GET    /api/pages/detail.php?id=X
PUT    /api/pages/detail.php?id=X
DELETE /api/pages/detail.php?id=X
POST   /api/groups/index.php
PUT    /api/groups/detail.php?id=X
DELETE /api/groups/detail.php?id=X
POST   /api/links/index.php
PUT    /api/links/detail.php?id=X
DELETE /api/links/detail.php?id=X
GET    /api/public/page.php?slug=X
