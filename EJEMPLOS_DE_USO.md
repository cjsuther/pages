# Ejemplos de Uso - Gestor de Páginas Personales

## Ejemplo 1: Crear una Página de Portfolio Personal

### Paso 1: Registro

```
URL: /register
Email: juan@ejemplo.com
Contraseña: mipassword123
```

El sistema crea tu cuenta y te lleva directamente al Dashboard.

### Paso 2: Crear Nueva Página

Desde el Dashboard, click en "Nueva Página":

```
Título: Mi Portfolio Web
Descripción: Colección de mis proyectos y enlaces profesionales
URL: juan-portfolio
```

Resultado: `/juan-portfolio` será tu página pública.

### Paso 3: Personalizar Colores

En el editor de página, selecciona:

```
Color Primario: #2563EB (Azul)
Color Secundario: #7C3AED (Morado)
Color de Fondo: #F8FAFC (Gris claro)
Color de Texto: #1E293B (Gris oscuro)
```

## Funcionalidades Avanzadas

### Uso de Imágenes

Puedes usar:
- URLs directas de imágenes
- Imágenes de servicios como Imgur, Cloudinary
- Logos de redes sociales
- Screenshots de proyectos
- Fotos de productos

### Organización Efectiva

**Mejor práctica:**
1. Grupo principal arriba (Call-to-Action principal)
2. Grupos secundarios en el medio
3. Redes sociales al final
4. Máximo 3-5 grupos por página
5. 3-8 links por grupo

### URLs Personalizadas

Ejemplos de buenos slugs:
- `maria-portfolio`
- `restaurante-roma`
- `coach-fitness`
- `agencia-web`
- `tienda-artesanias`

Evitar:
- `mi-pagina-123` (poco profesional)
- `aaaa` (no descriptivo)
- `mi_página` (caracteres no permitidos)
